Information and Logarithms

Definitions
BitThe information in one fair yes/no choice: an answer that halves what is left.
Information in an answer−log2 p bits, where p is the probability, before asking, that the answer comes out that way.
Surprisal−log2 P(x), measured in bits.
Logarithmlog2 m = n iff 2n = m. log2 8 = 3, log2 0.5 = −1.
Ruleslog (a · b) = log a + log b. log (a ÷ b) = log a − log b. log (1 ÷ a) = −log a. log2 x = log10 x ÷ log10 2, for a calculator without log2.
Expected information gainWhat a question is worth before you hear the answer. P(yes) · (−log2 P(yes)) + P(no) · (−log2 P(no)).

Entropy

Definitions
EntropyH(X) = Σx P(x) · (−log2 P(x)). Average surprisal: how uncertain a listener still is.
Maximum entropylog2 N, reached when all N outcomes are equally likely.
Coding theoremNo code in which no word is the start of another averages fewer than H symbols per message; some such code comes as close as you like.

Worked example. Width, probability. Height, surprisal. Area, entropy, 1.75 bits. Four equally frequent objects, 2 bits. One object nearly always, close to 0.

Worked example. Equal frequencies. H = 0.25 · 2 + 0.25 · 2 + 0.25 · 2 + 0.25 · 2 = 2 bits. Unequal frequencies, each surprisal weighted by its probability.

Redundancy

Definitions
Redundancy1 − H ÷ Hmax. The share of the signal the message does not need.
NoiseRandom change to the signal between speaker and listener.

Worked example. English letters and the space, Hmax = log2 27 ≈ 4.75 bits. Patterns up to about eight letters, redundancy about 50% (Shannon 1948). Long contexts, about 1 bit a letter (Shannon 1951), redundancy 1 − 1 ÷ 4.75 ≈ 0.8. More context, less entropy, more redundancy. Lexicon B, none.

Literal listenerL0(x | m), how likely the listener thinks each object x is once she has heard message m. Given in the tables below.

Message costc per extra word, counted in bits.
Speaker's choiceThe true message with the fewest bits still needed plus cost.
