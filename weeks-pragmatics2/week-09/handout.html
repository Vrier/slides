The reference game

Definitions
ObjectsThe four objects of the Rational Speech Act handout, with the prior measured in class: 0.44, 0.09, 0.28 and 0.19.
MeaningA word or signal is true of an object if each of its words is in the object’s name.
DistributionPython: a dictionary from outcomes to probabilities. WebPPL: the result of Infer.
showPrints a distribution with two decimals.

Each section adds to the program so far. The Python is in handout.ipynb, and the WebPPL runs on the code page.

Python
from math import log2

objects = ["blue square", "green square",
           "blue circle", "green circle"]
prior = {"blue square": 0.44, "green square": 0.09,
         "blue circle": 0.28, "green circle": 0.19}
words = ["blue", "green", "square", "circle"]

def meaning(u, s):
    return all(w in s for w in u.split())

def show(d):
    for k, v in d.items():
        print(k, round(v, 2))
WebPPL

  return all(function(w) { return s.indexOf(w) >= 0 },
             u.split(" "))
}

var show = function(d) {
  return map(function(s) {
    return s + ": " + Math.exp(d.score(s)).toFixed(2)
  }, d.support())
}

1

The literal listener

Definitions
L0(s | u)The prior, with the objects of which u is false removed, divided by what is left.
InferRuns a function over every outcome of its random choices and returns the distribution of what it returns.
condition(c)Drops the run when c is false.
Example

Hearing blue.

Python
def L0(u):
    total = sum(meaning(u, s) * prior[s] for s in objects)
    return {s: meaning(u, s) * prior[s] / total for s in objects}

show(L0("blue"))
blue square 0.61
green square 0.0
blue circle 0.39
green circle 0.0
WebPPL
var L0 = cache(function(u) {
  return Infer(function() {
    var s = categorical({ps: prior, vs: objects})
    condition(meaning(u, s))
    return s
  })
})

show(L0("blue"))
["blue circle: 0.39","blue square: 0.61"]

2

The speaker

Definitions
S1(u | s)Each true utterance in proportion to 2α · U(u; s), with U(u; s) = log2 L0(s | u) − C(u).
factor(x)Weights the run by ex. score gives a natural logarithm, so factor(alpha * L0(u).score(s)) weights by L0(s | u)α, as the formula does with no cost.
Example

The blue square’s speaker at α = 1.

Python
def S1(s, alpha=1, utterances=None, cost=lambda u: 0):
    scores = {u: 2 ** (alpha * (log2(L0(u)[s]) - cost(u)))
              for u in (utterances or words) if meaning(u, s)}
    total = sum(scores.values())
    return {u: scores[u] / total for u in scores}

show(S1("blue square"))
blue 0.42
square 0.58
WebPPL
var S1 = cache(function(s, alpha) {
  return Infer(function() {
    var u = uniformDraw(filter(function(w) {
      return meaning(w, s)
    }, words))
    factor(alpha * L0(u).score(s))
    return u
  })
})

show(S1("blue square", 1))
["square: 0.58","blue: 0.42"]

3

The pragmatic listener

Definitions
L1(s | u)The prior times the speaker’s probability of u, divided by the evidence.
observe(d, v)Weights the run by the probability that the distribution d gives to v.
Example

Hearing circle, α = 1.

Python
def L1(u, alpha=1):
    products = {s: S1(s, alpha).get(u, 0) * prior[s]
                for s in objects}
    evidence = sum(products.values())
    return {s: products[s] / evidence for s in objects}

show(L1("circle"))
blue square 0.0
green square 0.0
blue circle 0.7
green circle 0.3
WebPPL
var L1 = cache(function(u, alpha) {
  return Infer(function() {
    var s = categorical({ps: prior, vs: objects})
    observe(S1(s, alpha), u)
    return s
  })
})

show(L1("circle", 1))
["green circle: 0.30","blue circle: 0.70"]

4

Costs

Definitions
Two-word signalblue square, green square, blue circle, green circle: true of one object only.
Cost1 bit for each word after the first. WebPPL works in natural logarithms, so a bit is Math.log(2).
Example

The blue square’s speaker with the two-word signals, α = 2.

Python
signals = words + ["blue square", "green square",
                   "blue circle", "green circle"]
cost = lambda u: len(u.split()) - 1

show(S1("blue square", alpha=2, utterances=signals, cost=cost))
blue 0.28
square 0.53
blue square 0.19
WebPPL
var signals = words.concat(["blue square", "green square",
                            "blue circle", "green circle"])
var cost = function(u) {
  return (u.split(" ").length - 1) * Math.log(2)
}

var S1cost = cache(function(s, alpha) {
  return Infer(function() {
    var u = uniformDraw(filter(function(w) {
      return meaning(w, s)
    }, signals))
    factor(alpha * (L0(u).score(s) - cost(u)))
    return u
  })
})

show(S1cost("blue square", 2))
["blue square: 0.19","square: 0.53","blue: 0.28"]

Scalar implicature

Definitions
StatesThe number of red apples in a bowl of three: 0, 1, 2 or 3.
Utterancesnone, true of 0; some, true of 1, 2 and 3; all, true of 3.

Replace the definitions of section 0 with these. The functions of sections 1 to 3 work unchanged.

Example

Flat prior, α = 1.

Python
objects = [0, 1, 2, 3]
prior = {0: 0.25, 1: 0.25, 2: 0.25, 3: 0.25}
words = ["none", "some", "all"]

def meaning(u, n):
    return {"none": n == 0, "some": n > 0, "all": n == 3}[u]

6

What you need to know

Concepts
  1. A model as a program; sampling against enumeration.
  2. condition, factor and observe.
  3. The literal listener, the speaker and the pragmatic listener as functions.
  4. α, costs and priors as parameters.
  5. What the speaker has seen.
Skills
  1. Run and edit an RSA program in WebPPL or in Python.
  2. Read a listener’s or a speaker’s distribution from the output.
  3. Predict the effect of a change to α, a cost or a prior before running it.
  4. Write the meaning of a new word.
  5. Match each line of the program to its line in the formulas.
