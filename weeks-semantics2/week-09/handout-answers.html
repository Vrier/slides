Truth functions and the material conditional

Definitions
Truth-functional connectiveA connective whose truth value is fixed by the truth values of its parts. Not, and, or.
Material conditionalA → C. False when A is true and C is false, true otherwise. Equivalent to ¬A ∨ C.
Valid inferenceNo row makes all the premises true and the conclusion false.
TautologyTrue in every row.
Paradoxes of material implicationFrom ¬A infer A → C. From C infer A → C. Both valid for →.

Indicatives and counterfactuals

Definitions
AntecedentThe if-clause, or protasis. The main clause is the consequent, or apodosis.
Indicative conditionalOrdinary tense in both clauses, read against what is known.
Counterfactual conditionalPast morphology in the antecedent and would in the consequent, read against an antecedent taken to be false.
Biscuit conditionalThe consequent holds whether or not the antecedent does. The if-clause says when the assertion is relevant.
Concessive conditionalEven if A, C. Asserts C, and adds that A would not change it.
Anankastic conditionalStates what is necessary for a goal. If you want X, you have to Y.

The strict conditional

Definitions
Accessibility relationR(w), the set of worlds accessible from w. For an epistemic R, the worlds compatible with what is known at w.
Strict conditionalIf A, C is true at w iff R(w) ∩ A ⊆ C. Every accessible A-world is a C-world.
Vacuous truthA strict conditional is vacuously true at w when R(w) contains no A-world.
Strengthening the antecedentFrom if A, C to if A and B, C.
Sobel sequenceIf A, C; if A and B, not C; if A and B and D, C … Each antecedent stronger, the whole consistent.
  1. (18)If kangaroos had no tails, they would topple over.
  2. (19)If kangaroos had no tails but used crutches, they would topple over.
Example
  1. R a fixed set of worlds. (18) strict, R ∩ NoTails ⊆ Topple. (19) strict, R ∩ NoTails ∩ Crutches ⊆ Topple.
  2. R ∩ NoTails ∩ Crutches ⊆ R ∩ NoTails, so strengthening is valid. Yet (18) is true and (19) false.

Similarity and the variably strict conditional

Definitions
Similarity orderingv ≤w u iff v is at least as similar to w as u is. Centred (w is closer to w than any other world) and total (any two worlds are comparable).
SpheresThe sets {v : v ≤w u}, nested around w.
Closest antecedent worldsMinw(A), the A-worlds to which no A-world is more similar. The A-worlds in the smallest sphere that contains one.
Limit assumptionMinw(A) is non-empty whenever A is true at some world.
Would counterfactualA □→ C is true at w iff C is true at all the closest A-worlds, Minw(A) ⊆ C.
Might counterfactualA ◇→ C is true at w iff C is true at some closest A-world. Equivalent to ¬(A □→ ¬C).
ContrapositionFrom A □→ C to ¬C □→ ¬A.

Stalnaker and Lewis

Definitions
Selection functionf(A, w), the A-world most similar to w. f(A, w) = w whenever A is true at w.
Stalnaker conditionalA > C is true at w iff C is true at f(A, w).
Uniqueness assumptionExactly one closest A-world. Minw(A) = {f(A, w)}.
Conditional excluded middle(A > C) ∨ (A > ¬C). Valid for >, invalid for □→.

Bizet is French and Verdi Italian at w0. Both are French at w1, Italian at w2, German at w3. w1 and w2 are equally close to w0, and w3 is further away.

  1. (32)If Bizet and Verdi had been compatriots, Bizet would have been Italian.
  2. (33)If Bizet and Verdi had been compatriots, Verdi would have been French.
  3. (34)If Bizet and Verdi had been compatriots, Bizet might have been Italian.
  4. (35)If Bizet and Verdi had been compatriots, Bizet would not have been Italian.
Example
  1. Lewis. Minw0(Compatriots) = {w1, w2}.
  2. (32) fails at w1, false. (33) fails at w2, false. (34) Bizet Italian at w2, true. (35) fails at w2, false. (32) and (35) both false, so conditional excluded middle fails for □→.
  3. Stalnaker. f(Compatriots, w0) = w1 or w2. If w1, (33) and (35) true, (32) false. If w2, (32) true, (33) and (35) false. (32) or (35) true either way.

The restrictor analysis

Definitions
Modal basef(w), a set of propositions. ∩f(w) is the set of worlds where all of them are true.
Restrictor analysisThe if-clause is added to the modal base, as below. For might, ∩f(w) ∩ A ∩ C ≠ ∅.
Material under the modal□(A → C), true iff ∩f(w) ⊆ A → C. For might, ◇(A → C).
Modal under the materialA → □C, true at w iff A is false at w or ∩f(w) ⊆ C. For might, A → ◇C.
Covert operatorA bare conditional restricts a silent operator, such as epistemic must or a generic always.
Tripartite structureOPERATOR [Restriction] [Nuclear scope]. The if-clause is the restriction. An adverb of quantification quantifies over cases.
⟦if A, must C⟧w = 1 iff ∩f(w)modal base ∩ ⟦A⟧if-clause ⊆ ⟦C⟧consequent
  1. (39)If we are on Route 80, we might be in Lockhart now.
Example
  1. Mary’s modal base ∩f(w) = {w1, w2, w3, w4}. On Route 80 at w1, w2. In Lockhart at w3. Actual world w2.
  2. Restrictor. ∩f(w) ∩ A ∩ C = {w1, w2} ∩ {w3} = ∅. (39) false.
  3. Material under the modal. A → C true at w3 and w4. (39) true.
  4. Modal under the material. A true at w2, and ◇C true, since w3 is in the base. (39) true.

Counterfactuals as restricted modals

Definitions
Ordering sourceg(w), a set of propositions that ranks worlds. For a counterfactual, the facts of w to be kept.
Orderingv ≤g(w) u iff every proposition in g(w) true at u is also true at v. v is at least as good as u.
Best worldsBestg(w)(X), the worlds in X with no strictly better world in X.
CounterfactualWith an empty modal base, A □→ C is true at w iff Bestg(w)(A) ⊆ C, and A ◇→ C iff Bestg(w)(A) ∩ C ≠ ∅.
Example
  1. The match model of section 3. g(w0) = {D, O}. w1 keeps D and O, w2 keeps O, w3 keeps D, w4 keeps neither.
  2. S-worlds w1 to w4. w1 keeps everything any other S-world keeps. Bestg(w0)(S) = {w1}. L true at w1. (23) true.
  3. w2 and w3 incomparable, each keeping a fact the other loses.
  4. Best agrees with Minw0 in this model.

What you need to know

Concepts
  1. Truth-functional connectives; the material conditional and its paradoxes.
  2. Indicative, counterfactual and biscuit conditionals; the if-clause as topic.
  3. The strict and the variably strict conditional; Sobel sequences.
  4. Similarity orderings; closest antecedent worlds; failures of strengthening, transitivity and contraposition.
  5. The selection function; conditional excluded middle; would and might counterfactuals.
  6. The restrictor analysis; tripartite structures; covert operators; ordering sources.
  7. Iterated counterfactuals; yo-yo conditionals.
Skills
  1. Give the truth table of the material conditional and test an inference with it.
  2. Classify a conditional as indicative, counterfactual, biscuit, concessive or anankastic.
  3. Evaluate a conditional under the material, strict and closest-worlds analyses.
  4. Draw a sphere model where strengthening, transitivity or contraposition fails.
  5. Decide a would and might pair under Stalnaker and under Lewis.
  6. Compute the restrictor analysis of a conditional, and best worlds from an ordering source.
  7. Show that the closest-worlds analysis can make a yo-yo conditional true.
