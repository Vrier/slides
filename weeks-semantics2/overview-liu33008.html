What the module is about

Semantics II is about intensional meaning. An extensional theory interprets each expression by what it picks out in the actual world: an individual, a set, a truth value. Some expressions make a contribution that cannot be stated this way. Modals, attitude verbs and conditionals are sensitive to how things could be or might have been, and to what someone believes, and two sentences with the same truth value can make different contributions under them. The standard response is to interpret expressions relative to possible worlds. The intension of an expression is a function from worlds to extensions, and a proposition is the set of worlds in which it is true.

Learning outcomes

On successful completion of this module, students will be able to:

  1. identify intensional contexts (modals, attitude reports, conditionals, intensional transitives) in real language data, using substitution and related diagnostics;
  2. work with the core notions of intensional semantics: intensions, propositions as sets of worlds, accessibility, modal logic;
  3. give formal analyses of modals, attitude reports and conditionals, and compare competing analyses of them;
  4. evaluate analyses of aspect, evidentiality and tense against new data.
