Sets, relations and functions

Definitions
SetAn abstract unordered collection of distinct objects. {2, 4, 11} = {4, 2, 11}.
Member2 ∈ {2, 4, 11}; 3 ∉ {2, 4, 11}. Anything can be a member, including other sets.
Predicate notation{x | x is a novel}: the set of all x such that x is a novel.
Cardinality|S| is the number of distinct members of S. |{3, 3, 3}| = 1.
Empty set∅ or {}: the set with no members. A singleton has exactly one member.
SubsetA ⊆ B iff for all x: if x ∈ A, then x ∈ B. Every set is a subset of itself. ∅ is a subset of every set.
Proper subsetA ⊂ B iff A ⊆ B and A ≠ B. Supersets reverse the relation: A ⊇ B iff B ⊆ A.
IntersectionA ∩ B = {x | x ∈ A and x ∈ B}. Disjoint sets have an empty intersection.
UnionA ∪ B = {x | x ∈ A or x ∈ B}. Inclusive or.
DifferenceA − B = {x | x ∈ A and x ∉ B}, also written A \ B. The complement A′ is everything outside A.
Ordered pair⟨19, 91⟩ ≠ ⟨91, 19⟩. Order matters.
RelationA set of ordered pairs. A × B, the Cartesian product, pairs each member of A with each member of B.
FunctionA relation from A to B is a function iff every element of A is mapped to one and only one member of B. In f(a) = b, a is the argument and b the value.
Sets in semantics
  1. (1)Tilly is a cat.t ∈ Cats
  2. (2)All cats stalk.Cats ⊆ Stalks
  3. (3)Kate is a lawyer and a doctor.k ∈ L ∩ D
  4. (4)No musician snores.M ∩ S = ∅
  5. (5)Some musician snores.M ∩ S ≠ ∅
  6. (6)Marilyn likes Neil.⟨m, n⟩ ∈ Likes

(1) and (2) together entail t ∈ Stalks. Transitive verbs denote relations because x likes y does not entail y likes x.

Entailment and truth functions

Definitions
EntailmentA set of sentences A entails a set of sentences B iff there is no way for A to be true and B false at the same time.
Atomic sentenceA sentence that cannot be broken down further. Symbolised by a propositional variable p, q, r, …
Truth-functionalThe truth of the complex sentence depends only on the truth of its subsentences.
TautologyTrue whatever truth values the atomic propositions take. p ∨ ¬p, p → p, ¬(p ∧ ¬p).
ContradictionFalse whatever truth values the atomic propositions take. p ∧ ¬p.
ContingentTrue on some assignments of truth values and false on others.
Equivalenceφ ≡ ψ iff they express the same truth function. Equally: they entail each other; φ ↔ ψ is a tautology.

Testing entailment with a truth table
  1. Symbolise the premises A and the conclusion B.
  2. Conjoin multiple premises into one formula.
  3. Draw the truth table for A and for B.
  4. A entails B iff no row has A = 1 and B = 0.

Material implication. p → q is false only when p is true and q is false. The natural language conditional needs something more sophisticated: (11) comes out true.

2

Propositional logic as a language

Definitions
Object languageThe language under study. Here: propositional logic.
MetalanguageThe language used to state when object-language sentences are true. The predicate is true belongs here (Tarski).
WFFWell-formed formula: a grammatical string of the logic.
Metavariableφ and ψ stand for any WFF. (p ∧ q) is a formula of the logic; (φ ∧ ψ) is a description of formulas.
Recursive ruleA rule whose output can be fed back in as its input. ¬p, ¬¬p, ¬¬¬p, …
ModelFor propositional logic: a function M from propositional letters to truth values.
Denotation⟦φ⟧M: the interpretation of φ with respect to M.
Syntax
  1. Lower case letters p, q, r, s, … are WFF.
  2. If φ is a WFF, then ¬φ is a WFF.
  3. If φ and ψ are WFF, then (φ ∧ ψ), (φ ∨ ψ), (φ → ψ) and (φ ↔ ψ) are WFF.
  4. Nothing else is a WFF. Outermost brackets may be omitted.
Semantics
  1. If p is atomic, ⟦p⟧M = M(p).
  2. ⟦¬φ⟧M = 1 iff ⟦φ⟧M = 0.
  3. ⟦φ ∧ ψ⟧M = 1 iff ⟦φ⟧M = 1 and ⟦ψ⟧M = 1.
  4. ⟦φ ∨ ψ⟧M = 1 iff ⟦φ⟧M = 1 or ⟦ψ⟧M = 1.
  5. ⟦φ → ψ⟧M = 1 iff ⟦φ⟧M = 0 or ⟦ψ⟧M = 1.
  6. ⟦φ ↔ ψ⟧M = 1 iff ⟦φ⟧M = ⟦ψ⟧M.
  1. (12)Let M(p) = 1, M(q) = 0, M(r) = 1. Then ⟦p ∨ q⟧M = 1 and ⟦¬r⟧M = 0, so ⟦(p ∨ q) → ¬r⟧M = 0.

Tarski 1944. The semantic conception of truth. Philosophy and Phenomenological Research 4: 341–376.

3

Predicate logic

Definitions
Individual constantn (Neil), m (Marilyn). Denotation fixed within a model.
Variablex, y, z. Denotation not fixed by the model. Constants and variables are terms.
PredicateOne-place: laughs, singer. Two-place: sees, likes. Three-place: shows.
Atomic formulaIf π is a one-place predicate and α a term, π(α) is a formula. If π is two-place and α, β are terms, π(α, β) is a formula. Negation and the binary connectives build complex formulas as in block 2.
ModelM = ⟨D, I⟩: a domain of individuals D and an interpretation function I for all the basic expressions.
InterpretationI maps constants to members of D, one-place predicates to sets of individuals from D, two-place predicates to sets of ordered pairs of individuals from D.
  1. (13)Neil laughs.laughs(n)
  2. (14)Marilyn sees Neil.sees(m, n)   subject first
  3. (15)Neil shows Marilyn Edith.shows(n, m, e)
  4. (16)Marilyn loves Neil and Neil isn’t tall.loves(m, n) ∧ ¬tall(n)
Example model M1

D1 = {Harriet, Raj, Chris}. I1(h) = Harriet, I1(r) = Raj, I1(c) = Chris. I1(smart) = {Harriet}. I1(likes) = {⟨Harriet, Raj⟩, ⟨Harriet, Chris⟩, ⟨Raj, Harriet⟩, ⟨Raj, Chris⟩, ⟨Chris, Harriet⟩, ⟨Chris, Raj⟩}.

Semantics
  1. If α is a non-logical constant, ⟦α⟧M = I(α).
  2. ⟦π(α)⟧M = 1 iff ⟦α⟧M ∈ ⟦π⟧M.
  3. ⟦π(α, β)⟧M = 1 iff ⟨⟦α⟧M, ⟦β⟧M⟩ ∈ ⟦π⟧M.
  4. Negation and the binary connectives: as in block 2.
  1. (17)⟦smart(h)⟧M1 = 1, since Harriet ∈ {Harriet}.
  2. (18)⟦likes(r, r)⟧M1 = 0, since ⟨Raj, Raj⟩ ∉ I1(likes).

Quantifiers, variables and assignments

Definitions
∃The existential quantifier: there is.
∀The universal quantifier: for all.
ScopeThe bracketed formula a quantifier applies to.
Bound variableA variable in the scope of a quantifier on that variable. The quantifier fixes its interpretation.
Free variableA variable that no quantifier binds. In ∃x.[cat(x)] ∧ purrs(x) the second x is free.
Assignment functiong maps each variable to an individual in D.
g[x ↦ k]The assignment just like g, except that x is mapped to k.
Denotation⟦·⟧M,g: relativised to a model and an assignment.
Syntax
  1. If u is a variable and φ is a formula, [∀u.φ] is a formula.
  2. If u is a variable and φ is a formula, [∃u.φ] is a formula.
  1. (19)Some cat purrs.∃x.[cat(x) ∧ purrs(x)]
  2. (20)Every cat purrs.∀x.[cat(x) → purrs(x)]
  3. (21)No cat lays eggs.¬∃x.[cat(x) ∧ layseggs(x)]

∃ pairs with ∧. ∀ pairs with →.

Scope ambiguity
  1. (22)Every linguist admires a philosopher.
    a. ∀x.[linguist(x) → ∃y.[philosopher(y) ∧ admires(x, y)]]   possibly a different philosopher each
    b. ∃y.[philosopher(y) ∧ ∀x.[linguist(x) → admires(x, y)]]   one philosopher for all
Semantics
  1. ⟦x⟧M,g = g(x).
  2. ⟦∃x.φ⟧M,g = 1 iff there is an individual k ∈ D such that ⟦φ⟧M,g[x ↦ k] = 1.
  3. ⟦∀x.φ⟧M,g = 1 iff for every individual k ∈ D, ⟦φ⟧M,g[x ↦ k] = 1.
  1. (23)In M1: ⟦∃x.smart(x)⟧M1,g = 1, taking k = Harriet. ⟦∀x.smart(x)⟧M1,g = 0, since k = Raj fails.

Composition

Steps of a semantic analysis
  1. Lexical knowledge. Give the syntactic structure. Give the lexical entry for each terminal node.
  2. Composition. Compute the denotation of each node from the composition rules and the terminal nodes. Give the denotation of the whole tree as an expression of predicate logic.
  3. Modelling. Give the denotation of that expression relative to a model and an assignment function.
Composition rules
Function ApplicationIf γ has subnodes α of type ⟨σ, τ⟩ and β of type σ, then ⟦γ⟧M,g = ⟦α⟧M,g(⟦β⟧M,g).
Predicate ModificationIf γ has subnodes α and β, both of type ⟨e, t⟩, then ⟦γ⟧M,g = λx.⟦α⟧M,g(x) ∧ ⟦β⟧M,g(x).
  1. (29)Harry cherishes Ron.
    ⟦cherishes Ron⟧= [λy.λx.cherishes(x, y)](r)FA= λx.cherishes(x, r)⟦Harry cherishes Ron⟧= [λx.cherishes(x, r)](h)FA= cherishes(h, r)
  2. (30)Every dog is good.
    ⟦every dog⟧= [λX.λY.∀x.X(x) → Y(x)](λz.dog(z))FA= λY.∀x.dog(x) → Y(x)⟦every dog is good⟧= [λY.∀x.dog(x) → Y(x)](λz.good(z))FA= ∀x.dog(x) → good(x)

    ⟦happy dog⟧= λx.happy(x) ∧ dog(x)PM⟦Fiona is a happy dog⟧= [λx.happy(x) ∧ dog(x)](f)FA= happy(f) ∧ dog(f)

Generalised quantifiers

Definitions
DeterminerA relation between two sets. Type ⟨⟨e, t⟩, ⟨⟨e, t⟩, t⟩⟩. DET(A)(B): the determiner combines first with A, then with B.
Generalised quantifierThe denotation of a determiner plus a noun: a set of sets. Type ⟨⟨e, t⟩, t⟩. ⟦every dog⟧M,g = {X : ∀y.dog(y) → X(y)}, the set of properties that all dogs have.
ConservativeDET(A)(B) = DET(A)(A ∩ B). Every dog is fast = Every dog is a fast dog.
ExtendableAdding things to the domain outside A and B does not change whether DET(A)(B) is true.
Upward monotoneDET(A)(B ∩ C) entails DET(A)(B). Every dog walks and is happy entails Every dog walks.
Downward monotoneDET(A)(B) entails DET(A)(B ∩ C). No dog walks entails No dog walks and is happy.
Non-monotoneNeither pattern holds. On the number line the quantifier turns on and then off again: between two and five dogs.

Events

  1. (34)Jones buttered the toast slowly, deliberately, in the kitchen, with a knife. ⊨ Jones buttered the toast.
Definitions
ReificationEvents are entities. Type v, variable e. Adverbials are predicates of events.
Davidsonian verbOne extra argument place, for the event. ⟦butter⟧M,g = λxe.λye.λev.butter(y, x, e).
Existential closure⟦∃⟧M,g = λV⟨v,t⟩.∃e.V(e). Sits at the top of the tree and closes off the event argument.
Adverb⟦slowly⟧M,g = λR⟨e,⟨v,t⟩⟩.λxe.λev.R(x)(e) ∧ slowly(e). Takes a Davidsonian VP and returns a Davidsonian VP.
Neo-DavidsonianVerbs are predicates of events only, type ⟨v, t⟩. Participants are introduced separately by thematic roles.
Thematic roleThe relation a participant bears to the event. Agent: the doer. Theme: the participant acted on. Instrument: the means.

Definitions
EventualityStates and events. States obtain; events occur. Events divide into activities, accomplishments and achievements.
StateHomogeneous, no internal structure. Usually no volition. know, believe, have, love, fear.

Tense and aspect

Definitions
SSpeech time.
EEvent time: E = τ(e), the runtime of the event e.
TTopic time, or reference time: the time the sentence is about. Adverbials like yesterday and at 5pm pick it out.

TenseLocates the topic time relative to the speech time.
Viewpoint aspectRelates the event time to the topic time.
