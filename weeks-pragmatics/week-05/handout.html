Context Update

0

Context sets and update

Definitions
Common groundThe propositions the participants in a conversation mutually accept for its purposes.
PropositionA set of worlds, the worlds where a sentence is true. ⟦S⟧ is a function from worlds to 1, 0 or #.
Context setThe worlds where every proposition in the common ground is true. Written c.
Updatec + S = {w ∈ c : ⟦S⟧(w) = 1}. Accepting an assertion removes the worlds where it is false.

Model. Each world settles the sentences below about Ed. # marks a sentence that has no truth value at a world.

w1w2w3w4w5w6
C Ed has childrenTTTFFT
B Ed's children are baldTFT##F
U Ed used to smokeTTFTFF
N Ed smokes nowFTFFFF
Worked
  1. c0 = {w1, w2, w3, w4, w5, w6}, a context where nothing about Ed is settled.
  2. c0 + Ed has children = {w1, w2, w3, w6}. w4 and w5 drop out.

Exercise.

(a)Compute c0 + Ed used to smoke.
(b)Compute (c0 + Ed used to smoke) + Ed smokes now.
(c)Find a sentence about Ed whose update leaves c0 unchanged, and one whose update leaves it empty.

Stalnaker 1978. Assertion. Syntax and Semantics 9: 315–332.

Stalnaker 2002. Common ground. Linguistics and Philosophy 25: 701–721.

Presupposition as a condition on update

Definitions
Presupposition⟦S⟧ is defined only if p. Where p is false, ⟦S⟧(w) = #.
Admittancec admits S iff c ⊆ p, every world in c a p-world.
Definednessc + S is defined only if c admits S.

Ed stopped smoking presupposes U. It is true where Ed used to smoke and no longer does, false where he still smokes, and # where he never smoked.

Worked
  1. c1 = {w1, w2, w4}. Every world is a U-world, so c1 admits Ed stopped smoking.
  2. c1 + Ed stopped smoking = {w1, w4}. w2 drops out, since Ed still smokes there.
  3. c0 + Ed stopped smoking is undefined. w3, w5 and w6 are not U-worlds.
Contextc + Ed's children are baldc + Ed stopped smoking
c2 = {w1, w3}
c3 = {w1, w2, w3, w6}
c4 = {w4, w5}
c5 = {w2}

Exercise.

(a)Fill each cell with the result of the update, or # where the update is undefined.
(b)Say which presupposition of Ed's children are bald decides the first column.
(c)c5 + Ed stopped smoking is defined, but the result is empty. Say why this is not a case of presupposition failure.

2

Accommodation

Definitions
AccommodationWhere c does not admit S, the hearer first replaces c with c ∩ p and then updates: (c ∩ p) + S.
Presupposition failurec ∩ p = ∅. No world is left to update, and the utterance cannot be accepted as it stands.
Worked
  1. c0 does not admit Ed stopped smoking. c0 ∩ U = {w1, w2, w4}.
  2. (c0 ∩ U) + Ed stopped smoking = {w1, w4}.

Exercise.

(a)Compute c0 + Ed's children are bald with accommodation.
(b)Compute c3 + Ed stopped smoking with accommodation.
(c)Take c = {w3, w5, w6}. Say what happens with Ed stopped smoking, and give the reply a hearer might make.
(d)Compare (a) with (c0 + Ed has children) + Ed's children are bald. What does accommodation do that the explicit assertion also does?

3

Connectives

Definitions
Negationc + not A = c ∖ (c + A).
Conjunctionc + (A and B) = (c + A) + B.
Conditionalc + (if A, B) = c ∖ ((c + A) ∖ ((c + A) + B)).
Disjunctionc + (A or B) = (c + A) ∪ ((c ∖ (c + A)) + B).
Local contextThe context a part of a sentence updates. For B in A and B, c + A. For B in A or B, c ∖ (c + A).
Worked
  1. c1 + not (Ed stopped smoking) = c1 ∖ (c1 + Ed stopped smoking) = {w1, w2, w4} ∖ {w1, w4} = {w2}.
  2. c0 + not (Ed stopped smoking) is undefined, since c0 + Ed stopped smoking is. The presupposition survives the negation.
Sentence, updating c0Local context of the part with the triggerResult
(1)Ed has children and Ed's children are bald.
(2)Ed's children are bald and Ed has children.
(3)If Ed has children, Ed's children are bald.
(4)Either Ed has no children or Ed's children are bald.
(5)Ed used to smoke and he stopped smoking.

4

Deriving projection

Definitions
Presupposition of a complex sentenceThe weakest condition on c under which the update is defined for every c that meets it.
HoleA construction whose update is defined only where its part's update is. Negation is one: c + not A needs c + A.
FilterA construction that updates a part in a local context which can supply that part's presupposition.
Proviso problemThe gap between the conditional presupposition the clauses predict and the unconditional one hearers often take away.
Worked
  1. Let B presuppose p. c + (A and B) is defined iff c + A ⊆ p.
  2. c + A ⊆ p iff every A-world in c is a p-world, so the conjunction presupposes if A, p.
  3. For (1) in section 3 this is if Ed has children, Ed has children, which every context meets.

Exercise.

(a)Show in the same way that if A, B presupposes if A, p, and that not A presupposes p where A presupposes p.
(b)Show that A or B presupposes if not A, p where B presupposes p, and use this to explain why (4) in section 3 presupposes nothing.
(c)If Theo hates sonnets, so does his wife. Give the presupposition the clauses predict, and the one a hearer takes away.
(d)If Ed is a scuba diver, he'll bring his wetsuit. Give the predicted presupposition, and say why here the hearer keeps it conditional.

Karttunen 1973. Presuppositions of compound sentences. Linguistic Inquiry 4: 169–193.

Geurts 1996. Local satisfaction guaranteed. Linguistics and Philosophy 19: 259–294.

Local accommodation

Definitions
Global accommodationAdding the presupposition to the context the whole sentence updates, as in section 2.
Local accommodationAdding it to a local context instead. For not A with A presupposing p: c ∖ ((c ∩ p) + A).

Ed doesn't have any children. So Ed's children aren't bald.

6

What you need to know

After this week you can
  1. Compute c + S for a sentence and a context set.
  2. Say whether a context admits a sentence, and compute the update or mark it undefined.
  3. Accommodate a missing presupposition, and recognise presupposition failure.
  4. Update with not, and, if and or, and name the local context of each part.
  5. Derive the presupposition of a complex sentence from the clauses, including conditional presuppositions.
  6. Compute local accommodation under negation.
