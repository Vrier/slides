Worlds, propositions and sets

Definitions
WorldA complete way things could be. Each world settles every sentence we care about as true or false. Worlds are written w1, w2 and so on, and w stands for any world.
Truth value1 for true, 0 for false. # where a sentence has no truth value at a world, because one of its presuppositions is false there.
⟦S⟧The meaning of a sentence S. It takes a world and gives a truth value. ⟦S⟧(w) = 1 reads “S is true at w”.
PropositionThe set of worlds where a sentence is true. On this sheet a capital letter such as C names both a sentence and its proposition. Italic A, B and S stand for any sentence, and p for any proposition. A p-world is a world in p.
Notation
{w1, w2}The set whose members are w1 and w2. Order and repetition do not matter.
x ∈ Ax is a member of A. x ∉ A: x is not.
A ⊆ BEvery member of A is a member of B.
A ∩ BThe members of both A and B.
A ∪ BThe members of A, of B, or of both.
A ∖ BThe members of A that are not in B.
∅The empty set, with no members.
{w ∈ A : …}The members w of A that meet the condition after the colon.
iffIf and only if.

Model. Each world settles the sentences below about Ed. # marks a sentence that has no truth value at a world.

w1w2w3w4w5w6
C Ed has childrenTTTFFT
B Ed's children are baldTFT##F
U Ed used to smokeTTFTFF
N Ed smokes nowFTFFFF
Worked
  1. ⟦C⟧(w1) = 1 and ⟦C⟧(w4) = 0. ⟦B⟧(w4) = #, since Ed has no children at w4.
  2. C = {w1, w2, w3, w6}. w4 ∉ C.
  3. C ∩ U = {w1, w2}. C ∖ U = {w3, w6}.

Exercise.

(a)Write out the propositions U and N as sets of worlds.
U = {w1, w2, w4}. N = {w2}.
(b)Is N ⊆ U? Is U ⊆ C? Give a reason for each answer.
N ⊆ U, yes: its only world, w2, is in U. U ⊆ C, no: w4 is in U but not in C.
(c)Compute C ∪ U, U ∖ N and N ∩ {w3, w5, w6}.
C ∪ U = {w1, w2, w3, w4, w6}. U ∖ N = {w1, w4}. N ∩ {w3, w5, w6} = ∅.
(d)At which worlds does B have no truth value, and why?
At w4 and w5. Ed has no children there, so the presupposition of B, that Ed has children, is false.

Partee, ter Meulen & Wall 1990. Mathematical Methods in Linguistics. Kluwer. Ch. 1.

Context sets and update

Definitions
Common groundThe propositions the participants in a conversation mutually accept for its purposes.
Context setThe worlds where every proposition in the common ground is true: the ways things could be, for all the conversation has settled. Written c. Subscripts, as in c0 and c1, name different context sets.
c + SThe context set after S is accepted in c. c + S = {w ∈ c : ⟦S⟧(w) = 1}: the worlds of c where S is true. The update removes the worlds where S is false.
Worked
  1. c0 = {w1, w2, w3, w4, w5, w6}, a context where nothing about Ed is settled.
  2. c0 + Ed has children = {w1, w2, w3, w6}. w4 and w5 drop out.

Exercise.

(a)Compute c0 + Ed used to smoke.
c0 + Ed used to smoke = {w1, w2, w4}.
(b)Compute (c0 + Ed used to smoke) + Ed smokes now.
{w1, w2, w4} + Ed smokes now = {w2}.
(c)Find a sentence about Ed whose update leaves c0 unchanged, and one whose update leaves it empty.
If Ed smokes now, he used to smoke is true at every world, so the update leaves c0 unchanged. Ed smokes now and he has no children is true at no world, since Ed smokes only at w2, where he has children, so the update leaves ∅. Any tautology and any contradiction would also do.

Stalnaker 1978. Assertion. Syntax and Semantics 9: 315–332.

Stalnaker 2002. Common ground. Linguistics and Philosophy 25: 701–721.

Presupposition as a condition on update

Definitions
PresuppositionS presupposes p when ⟦S⟧ is defined only if p: ⟦S⟧(w) is 1 or 0 at p-worlds and # elsewhere.
Admittancec admits S iff c ⊆ p: every world in c is a p-world, so the conversation already takes p for granted.
Defined, undefinedc + S is defined, and gives a context set, only if c admits S. Otherwise it is undefined, written #: the update cannot be carried out.

Ed stopped smoking presupposes U. It is true where Ed used to smoke and no longer does, false where he still smokes, and # where he never smoked.

Worked
  1. c1 = {w1, w2, w4}. Every world is a U-world, so c1 admits Ed stopped smoking.
  2. c1 + Ed stopped smoking = {w1, w4}. w2 drops out, since Ed still smokes there.
  3. c0 + Ed stopped smoking is undefined. w3, w5 and w6 are not U-worlds.
Contextc + Ed's children are baldc + Ed stopped smoking
c2 = {w1, w3}{w1, w3}#
c3 = {w1, w2, w3, w6}{w1, w3}#
c4 = {w4, w5}##
c5 = {w2}∅∅

Exercise.

(a)Fill each cell with the result of the update, or # where the update is undefined.
(b)Say which presupposition of Ed's children are bald decides the first column.
Ed has children. The update is defined only where every world in c is one where Ed has children, so c4, which holds w4 and w5, gives #.
(c)c5 + Ed stopped smoking is defined, but the result is empty. Say why this is not a case of presupposition failure.
c5 admits Ed stopped smoking, because Ed used to smoke at w2, so the presupposition is met. The result is empty because the assertion is false at w2, where Ed still smokes. The sentence is defined but false throughout the context. It clashes with what is already accepted; nothing is missing from the context.

Heim 1983. On the projection problem for presuppositions. WCCFL 2: 114–125.

Karttunen 1974. Presupposition and linguistic context. Theoretical Linguistics 1: 181–194.

Accommodation

Definitions
AccommodationWhere c does not admit S, the hearer first keeps only the p-worlds of c, the set c ∩ p, and then updates: (c ∩ p) + S.
Presupposition failurec ∩ p = ∅. No world is left to update, and the utterance cannot be accepted as it stands.
Worked
  1. c0 does not admit Ed stopped smoking. c0 ∩ U = {w1, w2, w4}.
  2. (c0 ∩ U) + Ed stopped smoking = {w1, w4}.

Exercise.

(a)Compute c0 + Ed's children are bald with accommodation.
c0 ∩ C = {w1, w2, w3, w6}, and (c0 ∩ C) + Ed’s children are bald = {w1, w3}.
(b)Compute c3 + Ed stopped smoking with accommodation.
c3 ∩ U = {w1, w2}, and (c3 ∩ U) + Ed stopped smoking = {w1}.
(c)Take c = {w3, w5, w6}. Say what happens with Ed stopped smoking, and give the reply a hearer might make.
c ∩ U = ∅, since Ed never smoked at w3, w5 or w6. This is presupposition failure. Nothing is left to update, and the hearer objects, “Hey, wait a minute. Ed never smoked.”
(d)Compare (a) with (c0 + Ed has children) + Ed's children are bald. What does accommodation do that the explicit assertion also does?
(c0 + Ed has children) + Ed’s children are bald = {w1, w2, w3, w6} + Ed’s children are bald = {w1, w3}, the same result as (a). Both remove the worlds where Ed has no children, w4 and w5, before the sentence is evaluated. Accommodation does this without the presupposition being asserted.

Lewis 1979. Scorekeeping in a language game. Journal of Philosophical Logic 8: 339–359.

von Fintel 2008. What is presupposition accommodation, again? Philosophical Perspectives 22: 137–170.

Connectives

Definitions
Negationc + not A = c ∖ (c + A). Update with A, then keep the worlds of c that did not survive.
Conjunctionc + (A and B) = (c + A) + B. Update with A, then update the result with B.
Conditionalc + (if A, B) = c ∖ ((c + A) ∖ ((c + A) + B)). Remove from c the A-worlds where B is false.
Disjunctionc + (A or B) = (c + A) ∪ ((c ∖ (c + A)) + B). Keep the A-worlds, and add the worlds where A is false and B is true.
Local contextThe context a part of a sentence updates. For B in A and B, c + A. For B in A or B, c ∖ (c + A).
Worked
  1. c1 + not (Ed stopped smoking) = c1 ∖ (c1 + Ed stopped smoking) = {w1, w2, w4} ∖ {w1, w4} = {w2}.
  2. c0 + not (Ed stopped smoking) is undefined, since c0 + Ed stopped smoking is. The presupposition survives the negation.
Sentence, updating c0Local context of the part with the triggerResult
(1)Ed has children and Ed's children are bald.c0 + Ed has children = {w1, w2, w3, w6}{w1, w3}
(2)Ed's children are bald and Ed has children.c0 = {w1, w2, w3, w4, w5, w6}#
(3)If Ed has children, Ed's children are bald.c0 + Ed has children = {w1, w2, w3, w6}{w1, w3, w4, w5}
(4)Either Ed has no children or Ed's children are bald.c0 ∖ (c0 + Ed has no children) = {w1, w2, w3, w6}{w1, w3, w4, w5}
(5)Ed used to smoke and he stopped smoking.c0 + Ed used to smoke = {w1, w2, w4}{w1, w4}

Exercise.

(a)Fill the table. Write # where the update is undefined.
(b)(3) and (4) give the same result. Say why, using the clauses above.
Both update Ed’s children are bald in the same local context, the worlds where Ed has children, and both keep every world where he has none. The conditional removes from c the worlds where Ed has children who are not bald; the disjunction keeps the worlds where he has no children and adds those where he has children who are bald. Either way the result is c0 without w2 and w6.
(c)Say which of the conjunctions (1), (2) and (5) would be defined if conjunction were defined as c + (A and* B) = (c + B) + A.
Only (2). With and*, the second conjunct is updated first, in c0. In (1) and (5) the second conjunct carries the trigger, so its presupposition is checked against c0 and fails. In (2) the trigger is in the first conjunct, which is now updated after Ed has children, so the update is defined and gives {w1, w3}.

Heim 1983. On the projection problem for presuppositions. WCCFL 2: 114–125.

Beaver 2001. Presupposition and Assertion in Dynamic Semantics. CSLI. Ch. 6.

Deriving projection

Definitions
Presupposition of a complex sentenceThe condition a context set must meet for the update with the whole sentence to be defined.
if A, pThe proposition true at every world where A is false or p is true: the worlds outside A, together with the p-worlds.
HoleA construction whose update is defined only where its part's update is. Negation is one: c + not A needs c + A.
FilterA construction that updates a part in a local context which can supply that part's presupposition.
Proviso problemThe gap between the conditional presupposition the clauses predict and the unconditional one hearers often take away.
Worked
  1. Let B presuppose p. c + (A and B) is defined iff c + A ⊆ p.
  2. c + A ⊆ p iff every A-world in c is a p-world, so the conjunction presupposes if A, p.
  3. For (1) in section 4 this is if Ed has children, Ed has children, which every context meets.

Exercise.

(a)Show in the same way that if A, B presupposes if A, p, and that not A presupposes p where A presupposes p.
if A, B. c + (if A, B) needs (c + A) + B, which is defined iff c + A admits B, that is iff c + A ⊆ p. Every A-world in c must then be a p-world, so the sentence presupposes if A, p. not A. c + not A = c ∖ (c + A) is defined iff c + A is, that is iff c ⊆ p, so not A presupposes p.
(b)Show that A or B presupposes if not A, p where B presupposes p, and use this to explain why (4) in section 4 presupposes nothing.
c + (A or B) needs (c ∖ (c + A)) + B, which is defined iff c ∖ (c + A) ⊆ p. Every world in c where A is false must then be a p-world, so the sentence presupposes if not A, p. In (4), A is Ed has no children and p is Ed has children, so the presupposition is if Ed has children, Ed has children, which every context meets.
(c)If Theo hates sonnets, so does his wife. Give the presupposition the clauses predict, and the one a hearer takes away.
Predicted, if Theo hates sonnets, he has a wife. Taken away, Theo has a wife. Hating sonnets has nothing to do with having a wife, so hearers strengthen the conditional, which is the proviso problem.
(d)If Ed is a scuba diver, he'll bring his wetsuit. Give the predicted presupposition, and say why here the hearer keeps it conditional.
Predicted, if Ed is a scuba diver, he has a wetsuit. Here the condition is plausible on its own, since scuba divers usually own wetsuits, so the hearer has no reason to strengthen it to Ed has a wetsuit.

Karttunen 1973. Presuppositions of compound sentences. Linguistic Inquiry 4: 169–193.

Geurts 1996. Local satisfaction guaranteed. Linguistics and Philosophy 19: 259–294.

Local accommodation

Definitions
Global accommodationAdding the presupposition to the context the whole sentence updates, as in section 3.
Local accommodationAdding it to a local context instead. For not A with A presupposing p: c ∖ ((c ∩ p) + A). Update the p-worlds of c with A, then keep the worlds of c that did not survive.

Ed doesn't have any children. So Ed's children aren't bald.

Exercise.

(a)Compute c0 + Ed doesn't have any children. Call the result c6.
c6 = c0 ∖ (c0 + Ed has children) = {w4, w5}.
(b)Say why c6 + Ed's children aren't bald is undefined, and why global accommodation cannot repair it.
c6 + Ed’s children aren’t bald needs c6 + Ed’s children are bald, which is undefined, because Ed has no children at w4 or w5. Global accommodation would replace c6 with c6 ∩ C = ∅. That is presupposition failure, and it contradicts the first sentence.
(c)Compute the update with local accommodation, and say what the second sentence adds to c6.
c6 ∖ ((c6 ∩ C) + Ed’s children are bald) = c6 ∖ (∅ + Ed’s children are bald) = c6 ∖ ∅ = {w4, w5}. The second sentence adds nothing to c6. With local accommodation it says that Ed does not have children who are bald, which c6 already settles.
(d)Ed's children aren't bald. Said out of the blue to a hearer who knows nothing about Ed, which accommodation would the hearer make, and why?
Global accommodation. Nothing in the context rules out Ed having children, so the hearer adds the presupposition to the whole context, and (c0 ∩ C) + Ed’s children aren’t bald = {w2, w6}. Local accommodation is a last resort, for when global accommodation would contradict the context, as in (b).

Heim 1983. On the projection problem for presuppositions. WCCFL 2: 114–125.

von Fintel 2008. What is presupposition accommodation, again? Philosophical Perspectives 22: 137–170.
