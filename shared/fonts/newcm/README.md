# New Computer Modern (web copies)

The typeface of LaTeX documents, in the heavier **Book** weight, which holds up better on a
projector and in print than the regular cut.

- Source: CTAN, `fonts/newcomputermodern` (package version 8.1.1), Antonis Tsolomitis, 2019–2026.
- Files here are the original OTFs re-wrapped as WOFF2 with fontTools. No glyphs, tables or names
  were changed and nothing was subset.

  NewCMMono10, NewCMMath Book). NewCM10-Regular is GPL3+FE and is **not** included.
  Full text: https://mirrors.ctan.org/fonts/newcomputermodern/License.txt
- Wired up by `shared/font-latex.css`.
