Pattern library · deck slides

One canonical copy of every shared pattern

How to use
Arrow through the patterns, then copy the matching <section> from this file's source into your week's deck. Slide text is directly editable HTML.
Two adjustments
This file sits one level deep — asset paths here are ../shared/…, but week files use ../../shared/…. And the chrome (.b-rail, steppers) is left empty by design: the module's *-rail.js fills it from <body data-week="N">, which is why the rail column renders blank in this library.
Theming
Everything here is in base TCD blue. Add the module's theme link (theme-teal / -indigo / -burgundy / -rust) and the same markup recolours itself — no class changes.
Adding a pattern? Promote its CSS to shared/deck-slides.css first, then add one canonical slide here.
